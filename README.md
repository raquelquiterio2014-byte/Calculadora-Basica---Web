# Calculadora web

Calculadora de estudo com HTML, CSS e JavaScript: soma, subtração, multiplicação, divisão, quadrado, cubo e raiz quadrada.

## Executar

Abra `index.html` no navegador com `style.css` e `script.js` na mesma pasta. Informe o primeiro número; as quatro operações binárias também exigem o segundo. Clique em **Calcular**.

O programa informa campos vazios, divisão por zero e tentativa de raiz real de número negativo. Não há servidor nem armazenamento. O código da página que antes aparecia no README está em arquivos próprios; versões anteriores permanecem no histórico Git.
